Movscript

Video creation for Vibe Motion, AI-planned production, and automatic editing.

GitHub Pages exposes two supported install paths: install only the Agent plugin from the command line, or install the Desktop app for the full local visual workspace. Release packages are downloaded from GitHub Releases.

Choose one install path

Path 1

Agent plugin only

Use this when Codex or another Agent provider should access Movscript without installing Desktop. The installer only registers the plugin package.

curl -fsSL https://movscript.github.io/movscript/install-plugin.sh | sh
Download plugin package

Path 2

Desktop app

Use this when you want the local visual workspace. Desktop reuses the same local runtime daemon as Agent Plugin and CLI.

curl -fsSL https://movscript.github.io/movscript/install-desktop.sh | sh
Apple Silicon arm64 DMG Intel Mac x64 DMG

Recommended downloads are selected for your device when detection is available.

Paste that in macOS Terminal. The script explains what it will do before installing the latest desktop app into /Applications.

方式一

只安装 Agent 插件

适合让 Codex 或其他 Agent provider 访问 Movscript，但不安装 Desktop。安装器只注册插件包。

方式二

安装 Desktop 应用

适合需要本地可视化工作台的用户。Desktop 与 Agent 插件和 CLI 复用同一个本机 runtime daemon。

curl -fsSL https://movscript.github.io/movscript/install-desktop.sh | sh
