Movscript

Video creation for Vibe Motion, AI-planned production, and automatic editing.

Movscript supports macOS Apple Silicon, macOS Intel, and Windows x64. Release packages are downloaded from GitHub Releases.

🚀 Install Movscript

curl -fsSL https://movscript.github.io/movscript/install.sh | sh
Apple Silicon arm64 DMG Intel Mac x64 DMG

Recommended downloads are selected for your device when detection is available.

Paste that in macOS Terminal. The script explains what it will do before installing the latest desktop app into /Applications.

Windows x64 Intel / AMD installer

Recommended downloads are selected for your device when detection is available.

Download the latest x64 .exe installer from GitHub Releases. The installer lets you choose the program installation directory.
