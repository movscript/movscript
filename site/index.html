Movscript

Video creation for Vibe Motion, AI-planned production, and automatic editing.

面向 Vibe Motion、AI 规划成片与自动剪辑的视频创作工具。

Movscript currently supports macOS Apple Silicon and Windows x64. Release packages are downloaded from GitHub Releases.

English / 简体中文

🚀 Install Movscript / 安装 Movscript

curl -fsSL https://movscript.github.io/movscript/install.sh | sh

Paste that in macOS Terminal. The script explains what it will do before installing the latest arm64 desktop app into /Applications.
将这段命令粘贴到 macOS 终端中运行。脚本会在安装最新 arm64 桌面应用到 /Applications 前说明将要执行的操作。

Download Windows x64 installer

Download the latest Windows x64 .exe installer from GitHub Releases. The installer lets you choose the program installation directory.
从 GitHub Releases 下载最新 Windows x64 .exe 安装器。安装器会让你选择程序安装目录。
