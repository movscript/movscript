Official LobeHub icon SVG files for the community web app.

Source package:

- `@lobehub/icons-static-svg@1.91.0`

Files are served from `/assets/lobe-icons/{name}.svg`.

`lobe.svg` is a compatibility copy of the official `lobehub.svg` asset.

The same files are mirrored to `enterprise/apps/web/public/assets/lobe-icons`
and `enterprise/apps/web/public/lobe-icons`.
